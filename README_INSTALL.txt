CFL DAILY DATA INPUT - GITHUB PWA

1) index.html ko Notepad me open karein.
2) PASTE_YOUR_APPS_SCRIPT_EXEC_URL_HERE ko apne deployed Apps Script /exec URL se replace karein.
3) Is folder ki sabhi files GitHub repository ke root me upload karein.
4) GitHub > Settings > Pages > Deploy from a branch > main > /(root) > Save.
5) GitHub Pages URL open karein.

INSTALL:
Android Chrome: menu (3 dots) > Install app / Add to Home screen.
iPhone Safari: Share > Add to Home Screen > Add.
Windows Chrome/Edge: address bar Install icon ya Menu > Install app.

IMPORTANT:
- Apps Script backend public nahi hoga.
- Service worker sirf local PWA shell files cache karta hai.
- Live data entry, Google Sheet sync, photo upload ke liye internet required hai.
